About

How I test

I start with failures that would affect users or block a release, then choose the quickest reliable check. For APIs, that means testing both contracts and behavior. For AI workflows, it means validating structured outputs in code and evaluating judgment calls against recorded evidence.

My work spans API, browser, and mobile automation with Playwright, Selenium, and Appium. At PwC, I also built and deployed React and Node.js applications.
